# @emsenn/producing-a-newswire

Projection package for turning producing outputs into canonical newswire capital.

The first producer is Cassia-shaped divination: daily indicator records become `ClaimStateBundle`s.
A downstream `organizing-a-newswire` can store and serve those bundles; a downstream `organizing-a-content-mill` can project the lossy claim-set view into feeds, pages, and other publication surfaces.
